# Online Ordering Playground

A browser-based Python playground built using WebAssembly (Pyodide) that allows users to write and execute Python code directly in the browser.

This project simulates an online ordering system while demonstrating how Python can run client-side using a WebAssembly runtime.

---

## 🚀 Project Goals

- Execute Python in the browser using Pyodide
- Build a mini online ordering system
- Integrate a browser-based code editor
- Capture and display Python output dynamically
- Explore WebAssembly-based Python execution

---

## 🧠 Why This Project?

Most web apps rely on server-side Python. This project demonstrates how Python can run entirely in the browser using WebAssembly, removing the need for a backend server.
